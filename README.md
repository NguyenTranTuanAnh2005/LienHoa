# LienHoa
## Technology Stack (Bộ công nghệ)

* Backend: Pure PHP (Thuần), MySQL Database.
* Frontend: JSX, JavaScript, CSS (Tối ưu UI/UX với Quick Navigation).
* Artificial Intelligence: Ollama API (Model: Gemma AI running locally).
* Security: Cổng xác thực SMS OTP Validation bảo mật hồ sơ y tế.

## Core Features (Chức năng cốt lõi)

* Hệ thống HIS/ERP bệnh viện thu nhỏ (Doanh thu, Xét nghiệm, Nhập viện, Tin tức, Đặt lịch khám chuyên khoa).
* Phân quyền chặt chẽ 2 tài khoản (Admin Dashboard & Patient Profile).

## How to run (Hướng dẫn chạy - Rất quan trọng)

Ghi chú rõ: Cần bật XAMPP (Apache & MySQL) và chạy lệnh `ollama run gemma` trước khi khởi động dự án.
